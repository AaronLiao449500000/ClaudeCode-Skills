# Example Font Confirmation

推荐话术：

> 即将生成 Excalidraw 可编辑排版稿，请先确认字体：
> 1. 霞鹜文楷屏幕阅读版（默认，适合中文阅读）
> 2. Nunito（中性清爽）
> 3. Excalifont（手绘草图感）
> 4. Comic Shanns（技术/代码感）
> 请直接回复数字或字体名。

如果用户回复：

- `1` 或 `霞鹜文楷` → 生成 `excalidraw-lxgw-wenkai-screen.css`
- `2` 或 `Nunito` → 生成 `excalidraw-nunito.css`
- `3` 或 `Excalifont` → 生成 `excalidraw-excalifont.css`
- `4` 或 `Comic Shanns` → 生成 `excalidraw-comic-shanns.css`
