# INSTALL-OBSIDIAN-SNIPPET.md

## 作用

这个 CSS snippet 用于控制 Obsidian Excalidraw 中的文字显示字体。
它不会影响 `index.html`，只影响你在 Obsidian 中查看和编辑 `layout.excalidraw.md` 时的显示效果。

## 安装步骤

1. 打开 Obsidian
2. 进入：`设置 -> 外观 -> CSS 代码片段`
3. 打开 snippets 文件夹
4. 将生成的 CSS 文件复制进去
5. 回到 Obsidian，启用该 snippet
6. 重新打开或刷新 Excalidraw 文件

## 注意事项

- 如果你选择的是 `霞鹜文楷屏幕阅读版`，请确保本地已安装 `LXGW WenKai Screen`
- 如果本地没有对应字体，系统会回退到后备字体
- 该 snippet 只影响 Obsidian / Excalidraw 显示，不改变 HTML 文件本身

## 建议

- 中文排版优先：`霞鹜文楷屏幕阅读版`
- 中性简洁：`Nunito`
- 草图感：`Excalifont`
- 技术/代码感：`Comic Shanns`
